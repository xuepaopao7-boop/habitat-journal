# Habitat Journal

A multi-page static editorial site for Habitat Journal.

## Structure

- `index.html` — magazine-style home page
- `assets/css/styles.css` — shared responsive design system
- `assets/js/main.js` — mobile navigation and contact-page enhancement
- `articles/` — editorial story pages
- `about/`, `contact/` — publication pages
- `privacy/`, `affiliate-disclosure/`, `editorial-policy/` — policy pages

The site has no build step and can be deployed directly from the repository root on Cloudflare Pages.
